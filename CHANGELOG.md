# Changelog

All notable changes to `agency-web-design` will be documented in this file.

## [1.0.0] - 2026-11-24

### Added
- Initial release of `agency-web-design` tailored for multi-industry web agencies using pure HTML5/CSS, Automatic.css (ACSS), 1-level BEM, and Bricks Builder (`bricks-acss-stack`).
- `SKILL.md`: 3-layer agency design governance, Mandatory Pre-Build Gate, 4-step template workflow, and strict Anti-AI-Slop + Zero-Tailwind/React guardrails.
- `references/industry-archetypes.md`: 6 Agency Visual Archetypes and 12-industry blueprint matrix distilled from UI/UX Pro Max methodology.
- `references/typography-and-color-vn.md`: Verified Vietnamese-safe Google Fonts pairings, ACSS fluid scales, and 60-30-10 color contrast discipline.
- `references/anti-slop-and-composition.md`: Anti-AI-Slop bans, 12-pattern section composition catalog with no-repeat rhythm rule, and Visual Richness Floor distilled from Taste Skill.
- `references/critique-and-polish.md`: 5-dimension Art Director critique rubric, steering verbs, and bounded Playwright visual QA distilled from Impeccable.
- `references/bricks-acss-handoff.md`: Exact ACSS-mirror token contract, native Bricks DOM + 1-level BEM, handoff annotations, and DTCG `design-system.json` spec.
- `scripts/install-to-workspace.ps1`: Workspace installation helper script.
